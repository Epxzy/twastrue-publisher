Privacy policy

Twas True Publisher. Last updated 2026-10-08.

Who this is for

Twas True Publisher is a private tool run by one person, the owner of the YouTube channel 'Twas True. Only that person signs in. The tool is not offered to the public and no one else's data is collected.

What it accesses

With the channel owner's permission it uses two Google/YouTube permissions: upload videos to the owner's own YouTube channel, and read the owner's own channel information and public statistics (youtube.upload and youtube.readonly).

How data is used and stored

The access token Google issues is stored only on the owner's own computer and is used only to upload the owner's videos and read the owner's own channel numbers. Nothing is sent to any server run by us, and nothing is sold, shared, rented, or disclosed to third parties. We do not use Google user data for advertising, and no human reads it.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The tool also uses YouTube API Services; see the Google Privacy Policy.

Revoking access

The owner can revoke access at any time at security.google.com/settings/security/permissions. Deleting the local token file also ends access.

Contact

Questions can be sent through the 'Twas True YouTube channel's About page.
